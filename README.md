# 🌸 FocusForge

A cozy to-do app that turns finishing tasks into a small game. I built it to practice JavaScript and to make a productivity tool that's actually fun to open.

<img width="568" height="869" alt="FocusForge screenshot" src="https://github.com/user-attachments/assets/d7b3ac62-db05-4f3e-822c-c7bbc1d3f79d" />

## Features
- Add tasks and set priorities
- Earn XP, level up, and keep a daily streak
- A mascot that reacts to what you do, with speech bubble feedback
- Keyboard shortcuts for quick use
- Soft pastel design with custom CSS animations

## Built With
HTML, CSS, vanilla JavaScript (no frameworks)

## What I Learned
- Managing app state (tasks, XP, streaks) without a framework
- Building animations and UI feedback with CSS
- Designing a small system of rewards to keep users motivated

## Run It
Clone the repo and open `index.html` in your browser.
